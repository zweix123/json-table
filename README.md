# json-table

让 Agent 用 JSON 文件交付表格，用浏览器阅读。Agent 可直接读写文件，也可用 jq 处理数据，无需调用表格平台。

## 使用

1. 将 [SYSTEM_PROMPT.md](./SYSTEM_PROMPT.md) 复制到 Agent 的系统提示词中。
2. 让 Agent 生成表格 JSON 文件。
3. 用浏览器直接打开 [index.html](./index.html)。

点击顶部「选择文件…」，或直接将一个 JSON 文件拖到页面任意位置打开。无需启动服务。

页面无需安装依赖，文件仅在本机处理，最大 20 MB。支持排序、多列筛选和调整列宽，单元格直接显示完整内容。

打开文件后，点击页眉「导出为」选择 CSV（`.csv`）或 Excel（`.xlsx`）。导出包含列头，沿用 JSON 中的列顺序和原文件名，并保留当前筛选、排序后的行；没有匹配行时仅导出列头。全部在本机生成，无需联网。

CSV 使用带 BOM 的 UTF-8，支持中文、逗号、双引号和换行；可能被表格软件识别为公式的文本会加单引号前缀。Excel 保留数字、布尔值和文本类型（包括字符串编号的前导零），两种格式均将 `null` 导出为空单元格，对象和数组导出为 JSON 文本。需要保留字符串类型时优先选择 Excel，CSV 的类型由打开它的软件推断。超出 Excel 行列或单元格字符上限时会提示改用 CSV，不会截断数据。

点击列头漏斗即可筛选，无需切换筛选方式：短值列直接搜索并勾选，空值也是候选项；数值列选择大小比较或区间；长文本或超过 100 个不同值的列直接输入包含的关键词。同列多选满足任意一项即可，不同列条件需要同时满足。候选项旁的数量会根据其他列的筛选更新；搜索只缩小候选列表，点击「应用筛选」才更新表格。顶部条件标签可单独移除，「清空筛选」保留排序，「重置排序」保留筛选。

## 数据格式

```json
{
  "columns": ["事项", "数量", "已完成"],
  "rows": [
    {"事项": "接口验证", "数量": 3, "已完成": true},
    {"事项": "异常排查", "数量": 1, "已完成": false}
  ]
}
```

`columns` 决定列顺序，列名非空且唯一；每行字段与列名一致。保留数值、布尔值等 JSON 类型，缺失值用 `null`，订单号等标识用字符串。

## 开发

运行测试需要 Node.js 24+，无第三方依赖。页面本身不需要 Node.js。

```sh
npm test   # 运行测试
```

所有文件放在根目录：`index.html` 是独立页面，`json-table.test.mjs` 是测试，`SYSTEM_PROMPT.md` 是用户提示词，`package.json` 定义测试命令。
